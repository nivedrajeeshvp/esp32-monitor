# Hardware Design

This directory contains the KiCad hardware design files for the Nexus Monitor ESP32 Gas and Environmental Monitoring System.

## Design Files

- Schematic (`.kicad_sch`): Circuit diagram and component connections.
- PCB layout (`.kicad_pcb`): Component placement and routing.
- Project file (`.kicad_pro`): KiCad project configuration.

Design files and supporting documentation will be added here as they become available.

## Status

Hardware integration and validation are in progress.
